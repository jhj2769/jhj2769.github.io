Google Drive 접근 목적과 범위

트립줌인은 채널 운영자가 여행 영상을 제작하는 도구입니다. 운영자가 연결한 Google 계정의 Drive 파일을 조회하고 관리할 수 있는 권한을 요청합니다. 제작 과정에서는 파일과 폴더 이름, 식별자, 편집 템플릿, 기준 음성, 영상 제작용 원본을 읽습니다. 완성된 MP4를 지정한 폴더에 저장하고 중복 저장 여부를 확인합니다.

자료를 처리하는 곳

영상 편집과 검수는 GitHub Actions 실행 환경에서 이루어집니다. 이 과정에서 제작에 필요한 원본이 Google Drive에서 실행 환경으로 전송됩니다. Drive 연결에 사용하는 인증 정보는 비공개 저장소의 GitHub Actions Secrets에 보관합니다.

보관과 삭제

Drive의 원본과 완성 영상은 운영자가 삭제할 때까지 해당 계정에 보관됩니다. 실행 중 생성한 임시 작업 파일은 작업 종료 시 정리합니다. 검토용으로 별도 보관한 자료와 실행 기록은 GitHub 워크플로에 설정된 보관 기간에 따라 삭제됩니다.

접근 권한 철회

운영자는 Google 계정의 연결 관리에서 트립줌인을 선택해 Drive 접근 권한을 철회할 수 있습니다. 이미 저장된 영상은 Drive에서 직접 삭제할 수 있습니다.
